# $\color{#61E8EE}{\text{Verificação}\ \text{de}\ \text{Idade}\ \text{em}\ \text{PHP}}$ 
### que coleta o nome e ano de nascimento do usuário, calcula a idade e valida o acesso.
___
### $\color{#61EDC5}{\text{O}\ \text{que}\ \text{o}\ \text{código}\ \text{faz:}}$
Formulário HTML: Recebe Nome e Ano de Nascimento.


Cálculo da Idade: Subtrai o ano informado do ano atual.
___
### $\color{#61EDC5}{\text{Validação}\ \text{de}\ \text{Acesso:}}$
$\ge 18$ anos: Libera o acesso e salva o nome/idade no arquivo log_acessos.txt.


$< 18$ anos: Bloqueia o acesso sem salvar registros.
